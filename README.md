Sales & Business Performance Analytics Dashboard

Project Overview

A personal Power BI portfolio project simulating a retail/e-commerce company's sales reporting requirement for January–June 2026.

The dashboard helps management analyze sales performance, profitability, product and regional performance, customer segments, sales channels, targets, and returned/cancelled transactions.

Business Requirements

The report was designed to answer:

- What are the overall sales and profit?
- How are sales and quantity changing over time?
- Which products and regions perform best?
- Which customer segments contribute most to sales?
- Which sales channels perform best?
- How do actual sales compare with targets?
- What is the impact of returned and cancelled transactions?
- Which areas require management attention?

Tools & Technologies

- Power BI
- Power Query
- DAX
- Excel
- Data Modeling

Data Model

The project uses a star-schema-style model containing:

- Fact_Sales
- Dim_Customer
- Dim_Product
- Dim_Region
- Dim_Date
- Targets

Relationships were created between the fact and dimension tables to support interactive analysis.

Data Preparation

Power Query was used to:

- Prepare and clean the source tables
- Correct table headers
- Validate data types
- Check duplicate records
- Prepare the data for modeling

DAX Measures

Created measures including:

- Total Sales
- Total Cost
- Total Profit
- Total Quantity
- Target Sales
- Sales Variance

Dashboard Analysis

The report includes analysis of:

- Overall Sales
- Profitability
- Sales Trends
- Quantity Trends
- Product Performance
- Regional Performance
- Customer Segment Performance
- Sales Channel Performance
- Target vs Actual Sales
- Returned and Cancelled Business

Interactive slicers allow users to filter the analysis by region, customer segment, channel, and month.

Project Type

Personal portfolio project created to demonstrate practical Power BI, data modeling, Power Query, and DAX skills for entry-level Data Analyst and Junior BI roles.
